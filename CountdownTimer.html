Class: CountdownTimer

CountdownTimer(when, func, countItem, nameopt, keyopt, cacheObjopt)

Timer that updates a passed in Item with the number of seconds reamining on the Timer once a second.

Constructor

new CountdownTimer(when, func, countItem, nameopt, keyopt, cacheObjopt)

Creates a timer to run func at when and a looping timer to update countItem with the seconds remaining every second. Both timers start immediately.
